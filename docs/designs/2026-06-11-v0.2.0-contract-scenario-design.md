# 合同场景启用 设计文档

## 目标

让合同类文件审查走专属 prompt 路径、精准召回合同类知识库、给出符合合同审查习惯的报告。

## 用户场景

- **招投标代理**上传招标/投标文件 → 系统识别为 bidding → 加载招投标 prompt → 召回招投标法规
- **合同审查人员**上传《施工合同》《采购合同》 → 系统识别为 contract → 加载合同 prompt → 召回合同法规
- 用户可在 Step2 手动切换场景

## 技术方案

### 1. 文档类型自动识别
- 后端 `/inspection/parse` 解析后新增返回字段 `documentType`: 'bidding' | 'contract' | 'unknown'
- 识别规则：解析后的 markdown 中匹配关键词
  - contract：合同/甲方/乙方/签订/协议/付款/履约/违约金/不可抗力
  - bidding：招标/投标/评标/中标/投标保证金
- 优先返回第一个匹配的，未匹配返回 'unknown'

### 2. Step2 智能场景切换
- `InspectionReviewModal.vue` 在 Step2 显示文档类型 chip
- 文档类型 = contract 时，自动勾选 contract 知识库并取消 bidding（除非用户主动覆盖）
- 显示「已自动识别为{类型}类，已启用相关知识库」提示

### 3. 合同专属 Prompt
- `backend/app/prompts/inspection_prompts.py` 新增 `CONTRACT_SYSTEM` / `CONTRACT_USER` 模板
- 关注：合同双方权利义务对等性 / 违约责任明确性 / 金额与履约期限 / 不可抗力 / 争议解决 / 绝对化用语

### 4. Prompt 调度
- `agents/inspector.py` 根据 `application_scenario` 字段选择 prompt 模板
- 新增调度表：`{'bidding': BIDDING_*, 'contract': CONTRACT_*}`

### 5. 数据模型
- `InspectionRecord.document_type` 字段已存在（来自 Step1 解析）
- 无需新增 migration


### Step2 前端组件
- `KnowledgeTogglePanel.vue` 新增 prop `documentType`
- 新增 emit `update:selectedScenarios`

## 错误处理

- 关键词匹配不到 → 返回 'unknown'，Step2 仍显示但默认勾选 bidding（保留原行为）
- 合同 prompt 模板缺失 → 兜底用 bidding prompt（保持稳定）
