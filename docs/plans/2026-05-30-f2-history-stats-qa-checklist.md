# F2 历史数据统计 MVP 手工验收清单

## 环境准备

- 启动后端服务（FastAPI）
- 启动前端服务（Vite）
- 打开 `http://localhost:5173/statistics`

## 检查项

1. 正常态
- 页面顶部显示“数据统计”“最近 7 天”
- 卡片显示 3 项：上传文档数、违禁词出现率、额度消耗
- 趋势表格显示 7 天日期行

2. 加载态
- 首次进入页面时显示“加载中...”
- 加载完成后替换为数据或空态

3. 空态
- 当近 7 天无记录时显示“近 7 天暂无数据”
- 三个卡片均显示 0 或 0%

4. 错误态
- 停止后端后刷新页面
- 显示“加载失败”提示
- 点击“刷新”按钮可再次触发请求

5. 口径校验
- 确认 `违禁词出现率 = 命中文档数 / 上传文档数`
- 确认趋势数据累加与汇总卡片一致
