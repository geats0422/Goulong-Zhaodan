# 安全指南

## 强制安全检查

在提交之前：
- [ ] 无硬编码密钥（API 密钥、密码、令牌）
- [ ] 所有用户输入已验证
- [ ] SQL 注入防护（参数化查询）
- [ ] XSS 防护（HTML 净化）
- [ ] CSRF 保护已启用
- [ ] 身份验证/授权已验证
- [ ] 所有端点已限速
- [ ] 错误消息不泄露敏感数据

## 密钥管理

- 永远不要在源代码中硬编码密钥
- 始终使用环境变量或密钥管理器
- 在启动时验证所需密钥是否存在
- 轮换任何可能已泄露的密钥

## 安全响应协议

如果发现安全问题：
1. 立即停止
2. 使用 **security-reviewer** 智能体
3. 在继续之前修复 CRITICAL 问题
4. 轮换任何已泄露的密钥
5. 检查整个代码库中是否存在类似问题

## Captcha 决策（2026-07-11 沉淀）

### 已弃用：Cloudflare Turnstile

原因：本地 dev 跳过机制反复失效；widget reset 与 built-in retry 冲突；8 次 fix 后回退。

### 替代方案

- SMS 验证码（已有：阿里云 SMS）
- 接口速率限制（goulong-auth）
- IP 异常检测（待评估：阿里云 WAF）

### 何时重新引入 Captcha

- 跨境高频滥用
- 单 IP 短时 > 100 请求
- 支付/密码重置被绕过速率限制
